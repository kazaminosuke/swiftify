## 対象と確認方法

- `src/app`、`src/core`、`src/playback`、`spotify-core`、`native-audio` の設定から
  Rust ABI、デバイス、バッファ、DSP、再生時計、通知までの流れを確認した。Rust の文字列と
  ライブバッファは ABI に対になる解放関数があり、Qt 側はハンドルを所有する。
- `src/spotify` と `src/youtube` の OAuth、セッション、ページング、タイムアウト、
  プロジェクト設定を比較した。YouTube は手動リダイレクト、API キーの専用ヘッダー、PKCE と
  読み取り権限を確認した。Spotify と Google の実アカウントは使用していない。
- `src/library`、`src/stats`、`src/artwork`、`src/render`、`src/motion`、
  `src/theme`、`src/system` と `qml` のデータ境界、再描画、スキャン、設定・キャッシュ、
  ファイル保存、デスクトップ起動を追跡した。再生キューは曲のインスタンスIDとURIを別に扱う。
  両者の扱いは重複キュー、シャッフル、保存位置のテストも参照した。
- ライセンスは CMake インストールと Arch/RPM/Windows/macOS 設定、Qt と Rust の告知を確認した。
  `rodio` の Symphonia 0.5 系と Opus/WebM 用 0.6 系は異なる公開 ABI を使う。
  一本化はタグ、シーク、形式対応を比較した上で進める。MPL-2.0 の Vorbis/Opus と
  [MusicBeatSP のクレジット記録][beat-review] を参照した。
- 静的な検索、PR差分、Rust と Qt のテストで確認した。生成されたアセットのバイナリ、ベンダーの
  全実装、実アカウント、物理デバイスの音質、Windows/macOS ランタイムは実測範囲外。
  Gemini 4 Hydrogen のレビュー本文は、Fork のコミット・開発記録・Draft のレビュー内に見つからなかった。
  開発履歴は [#12 の handoff][handoff] と照合した。
